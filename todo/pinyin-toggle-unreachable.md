# TODO: 병음 노래 토글을 초기 설정 마법사 밖에서 켤 수 없는 문제

- **상태**: **수정 완료** (custom.6)
- **작성일**: 2026-08-06
- **분류**: 포크 전용 기능의 설정 접근성 결함. 업스트림에 없는 기능이므로 업스트림 동기화로 해결되지 않습니다

## 증상

설정에서 **병음 노래 폴더**를 지정했는데도 집회 미디어 화면 우측 상단에 **병음 토글 버튼이 나타나지 않습니다.** 폴더를 다시 지정해도, 앱을 재시작해도 마찬가지입니다.

## 원인 — 서로 모순되는 두 줄

[`SettingsPage.vue`](../src/pages/SettingsPage.vue) 의 `shouldShowSetting`:

```js
if (item.hidden) return false; // ① 무조건 숨김

// Pinyin settings are only available when congregation language is CHS
if (
  ['enablePinyinSongs', 'pinyinSongFolder'].includes(settingId) &&
  currentSettings.value?.lang !== 'CHS'
)
  return false; // ② 중국어면 보이게
```

②는 `enablePinyinSongs` 를 **명시적으로 나열**해 "중국어 회중에서는 보여준다"는 의도를 드러내지만, `settings.ts` 의 `enablePinyinSongs: { hidden: true }` 때문에 ①이 먼저 걸립니다. **②의 그 부분은 처음부터 죽은 코드였습니다.**

결과:

| 설정                | 설정 화면           | 활성화 경로                                                                     |
| ------------------- | ------------------- | ------------------------------------------------------------------------------- |
| `pinyinSongFolder`  | 중국어면 표시 ✅    | 설정에서 지정 가능                                                              |
| `enablePinyinSongs` | **절대 표시 안 됨** | [`SetupWizard.vue:159-161`](../src/pages/SetupWizard.vue#L159-L161) **한 곳뿐** |

그리고 그 마법사 단계(6단계)는 **5단계를 통과하는 시점에 `lang === 'CHS'` 여야** 나타납니다:

```js
step = currentSettings.lang === 'CHS' ? 6 : 7;              // 137행
<q-step v-if="currentSettings?.lang === 'CHS'" :name="6">   // 143행
```

**즉 그 한 단계를 놓치면 프로필을 지우고 다시 설정하지 않는 한 병음 기능에 도달할 수 없습니다.** 폴더만 지정해 놓으면 아무 일도 일어나지 않으므로, 사용자 입장에서는 "설정했는데 안 되는" 상태가 됩니다.

`hidden` 이 의도된 것이 아니라는 근거: 20개 언어에 `enablePinyinSongs` 와 **`enablePinyinSongs-explain`** 번역이 모두 들어 있습니다. 숨겨진 설정에는 설명 문구가 필요하지 않습니다.

## 실측 확인 (사용자 A/B 실험, 2026-08-06)

| 설치                                | 설정 방법                                  | 병음 토글                                                        |
| ----------------------------------- | ------------------------------------------ | ---------------------------------------------------------------- |
| **custom.5** 완전 삭제 후 신규 설치 | 회중 검색으로 설정                         | **없음** (이후 설정에서 폴더를 지정해도 안 나옴)                 |
| **custom.0** 완전 삭제 후 신규 설치 | 마법사에서 언어를 **수동으로** 중국어 선택 | **있음** (6단계가 나타나 폴더 지정 → `enablePinyinSongs = true`) |
| 위 프로필에 custom.5 덮어 설치      | —                                          | **있음** (custom.0 이 남긴 `true` 가 유지됨)                     |

버전 차이가 아니라 **마법사 6단계를 만났는지의 차이**입니다.

## 수정

`settings.ts` 에서 `enablePinyinSongs` 의 `hidden: true` 를 제거하고 `pinyinSongFolder` 와 같은 subgroup 에 두어 나란히 보이게 했습니다. ②의 CHS 게이트가 이미 존재하므로 **중국어 회중에서만 표시되고 다른 언어 사용자에게는 변화가 없습니다.**

## 남은 개선 여지

- 마법사 6단계 노출 조건이 `lang === 'CHS'` 인데, 회중 검색으로 언어가 정해지는 시점이 5단계 이후일 수 있습니다. 마법사 단계 순서를 언어 확정 이후로 옮기면 더 견고해집니다.
- `pinyinSongFolder` 가 `subgroup: 'cache'` 에 있는 것은 의미상 어색합니다(캐시와 무관). 별도 subgroup 이 적절하지만, 지금은 두 설정이 **함께 보이는 것**이 우선이라 그대로 두었습니다.

## 교훈

`hidden: true` 와 조건부 표시 로직이 **같은 키를 두 곳에서 다루면** 한쪽이 조용히 죽습니다. 설정을 숨길 때는 그 설정을 켜는 경로가 실제로 존재하는지 확인해야 합니다. 이 경우 활성화 경로가 초기 설정 마법사 한 곳뿐이었고, 그 단계는 조건부였습니다.
